# code.dzenyu.com

Personal site and blog built with [Astro](https://astro.build).

## Local Development

1. Install dependencies:
   ```bash
   npm install
   ```
2. Serve locally:
   ```bash
   npm run dev
   ```
   This binds to `--host`, so the site is also reachable from other devices
   on the same network (e.g. `http://<your-machine>.local:4321`).
3. Open http://localhost:4321

Or use the wrapper scripts, which install dependencies first:
```bash
./start-site.sh dev     # or: ./start-site.sh build
./stop-site.sh          # stop a running dev/preview server
```

Note: Pagefind's search index is only generated by `npm run build`
(`astro build && pagefind --site dist`) — `astro dev` serves straight from
source, so `/search/` shows an explanatory note instead of the search box
until you build and preview.

## Build

```bash
npm run build
```

Runs `astro build` and then indexes the output with [Pagefind](https://pagefind.app) for
static search. The production site is deployed from `dist/` via GitHub Actions
(`.github/workflows/deploy.yml`) to GitHub Pages.

## Structure

- `src/content/blog/` — blog posts (MDX)
- `src/content.config.ts` — blog collection schema
- `src/pages/[...slug].astro` — post routing (`/<yyyy>/<mm>/<dd>/<slug>/`)
- `src/data/legacy-redirects.ts` — redirect stubs for old Jekyll and pre-redesign post URLs
- `src/pages/` — site pages (home, blog, about, tags, search, 404)
- `src/components/`, `src/layouts/` — shared UI
- `public/assets/` — images, favicons, and `CNAME`
